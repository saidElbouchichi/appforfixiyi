# SCOPE FIXIYI

## MVP - Phases 0 a 8 (OBLIGATOIRE avant toute autre chose)
- Phase 0 : Audit workspace
- Phase 1 : Foundation (monorepo, TS, lint, docker, CI, contracts)
- Phase 2 : Auth (OTP phone, email, sessions, RBAC)
- Phase 3 : Marketplace (catalogue, profils, onboarding, verification, companies)
- Phase 4 : Requests (creation demande, medias, localisation, urgence)
- Phase 5 : Matching (eligibility, ranking, dispatch progressif, expansion rayon)
- Phase 6 : Chat (realtime, messages, attachments, anti-contact)
- Phase 7 : Offers (offres, contre-offres, negociation, acceptation, price lock)
- Phase 8 : Interventions (appointment, GPS, navigation, states, cancellation)

## V2 - Phases 9 a 12 (apres validation MVP)
- Phase 9 : Finance (paiements, wallet, top-up, commission, settlement, refund)
- Phase 10 : Trust (reviews, reputation, risk, disputes, moderation, support)
- Phase 11 : AI (gateway, orchestration, structured output, multimodal, tools)
- Phase 12 : Admin (dashboard, verification, moderation, finance, config, audit)

## V3 - Phases 13 a 15 (apres validation V2)
- Phase 13 : Mobile (Expo, auth, requests, map, chat, GPS, push, offline)
- Phase 14 : Hardening (security audit, perf, a11y, E2E, load, failure)
- Phase 15 : Production (docker, infra, secrets, monitoring, CI/CD, rollback)
